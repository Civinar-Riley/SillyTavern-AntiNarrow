# SillyTavern-AntiNarrow（防窄化 · 沉浸全宽）

让 SillyTavern（酒馆）里的**所有楼层内容铺满整条聊天列**——正文美化卡、开场页 iframe、思考折叠块、媒体行、普通文本，一个都不窄。

## 这是什么问题？

酒馆的消息行自带一套"挤压"结构：头像列（50px）+ `.mes` 左右内边距（各 10px）+ `.mes_block` 左内边距（10px）+ `.mes_text` 右侧按钮预留位（30px），合计约 **90~100px**。移动端聊天列本身就不宽，再被抠掉这一截，任何做成整页效果的 HTML（开场页闸门、状态栏卡片、酒馆助手渲染的 iframe）都会被挤成中间一条窄带——俗称"**边框窄化**"。

根因在**酒馆本体的消息行布局**，不是任何前端页面或美化样式的 CSS 写错了。社区里成熟的解法是清零这些内边距并把头像列挪出消息行——本项目把这套解法做成了独立的酒馆助手脚本，并且**全部可配置**。

## 功能

- **清零消息行内边距**：`.mes` / `.mes_block` / `.mes_text`，含思考折叠块与媒体行同源的 30px 右缘缩进（负边距成对处理，不会冲出边缘）
- **头像列搬进楼层数字栏**（默认）：宽度收益最大；也提供"收起"/"保留"两档
- **重roll条**：末楼底部自动预留 `‹ ›` 按钮空带，重roll不压正文；检测到宿主已开启沉浸类布局（`body.immersive-mode`）时自动让位
- **左右留白**：贴边 / 小(8px) / 中(14px) / 大(20px) 四档
- **聊天列宽**：可选拉满全屏 100vw（默认跟随酒馆"聊天宽度"滑条）
- **生效范围**：全平台（默认）或仅窄屏（断点可调）
- **设置面板**：酒馆助手脚本按钮「防窄化设置」开关，改动即时生效，localStorage 自动记忆
- **无痕停用**：停用/删除脚本自动还原头像、样式、面板，无残留
- **好脾气**：与其他沉浸/美化类脚本可同开（头像只搬一次、规则幂等），自动跳过已被搬走的头像

## 原理（一句话）

**不杀 iframe**。脚本跑在酒馆助手的隐藏 iframe 里，经 `window.parent.document` 向酒馆宿主页面注入一段 `!important` CSS（清零消息行内边距），并把头像列 DOM 搬进名字栏——iframe 里的页面本来就是 100% 填满可用宽度的，把可用宽度还给它们即可。完整分析见 [docs/窄化根因与修复原理.md](docs/窄化根因与修复原理.md)。

## 安装（二选一，不要同时启用）

**方式 A · 自包含（推荐）**

1. 下载 [`dist/酒馆助手脚本-防窄化沉浸全宽.json`](dist/酒馆助手脚本-防窄化沉浸全宽.json)
2. 酒馆 → 扩展（酒馆助手）→ 脚本库 → **全局脚本库** → 导入
3. 代码完整离线内置，版本固定，不受 CDN 影响

**方式 B · CDN 加载器（自动更新）**

下载 [`dist/酒馆助手脚本-防窄化沉浸全宽-CDN加载器.json`](dist/酒馆助手脚本-防窄化沉浸全宽-CDN加载器.json) 同样导入。脚本内容只有一行——

```js
import 'https://cdn.jsdelivr.net/gh/Civinar-Riley/SillyTavern-AntiNarrow@main/src/mt-antinarrow.js';
```

代码实时从 jsDelivr 拉取本仓库 `main` 分支，仓库更新后**无需重新导入**（CDN 缓存最长约 12 小时；把 `@main` 换成 `@v1.0` 可锁定版本）。缺点：断网或 jsDelivr 不可达时无效。

> 两种方式功能完全相同，都会注册脚本按钮「防窄化设置」；**同时导入会出现两个同名按钮**，选一种即可。

打开面板：确认脚本编辑页顶部**「按钮」开关已开启**（两个 JSON 均已预置「防窄化设置」按钮），点酒馆助手脚本按钮栏里的「防窄化设置」即可，按喜好调整。

## 设置面板

| 设置项 | 选项（默认加粗） | 说明 |
|---|---|---|
| 头像列 | **搬到名字栏** / 收起 / 保留 | 搬移=头像在名字栏显示、消息行让出整列；收起=纯 CSS 隐藏；保留=不动 |
| 聊天列宽 | **不动** / 拉满全屏 | 拉满时 `--sheldWidth` 一并覆盖为 100vw |
| 生效范围 | **全平台** / 仅窄屏 | 仅窄屏时按下面的断点生效 |
| 重roll条 | **开** / 关 | 末楼底部预留 `‹ ›` 空带；沉浸类布局开启时自动让位 |
| 左右留白 | 贴边 / **小(8px)** / 中(14px) / 大(20px) | 用 margin 实现，不影响宽度计算 |
| 窄屏断点 | **1000px** | 仅"仅窄屏"时有效，400~2000 可调 |

设置存于浏览器 localStorage（key `mtAntiNarrow.settings.v1`），换档即时生效。

不启动酒馆也能验证布局效果：仓库根目录跑 `python -m http.server 8791`，浏览器打开 `http://127.0.0.1:8791/tests/_script_host.html`，窗口调到 412px 宽即为手机视口。详见 [tests/README.md](tests/README.md)。

## 已知取舍

- "搬到名字栏"后，点头像放大/头像菜单不再可用（头像还在名字栏里显示，只是位置变了）
- 收起/搬移头像列会改变依赖头像列宽度的主题效果；全平台清零内边距也会改变桌面端楼层观感——都可以在面板里调回
