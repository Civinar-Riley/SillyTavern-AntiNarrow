# 本地模拟验证

无需安装酒馆或第三方库，从仓库根目录启动静态服务器：

```bash
python -m http.server 8791
```

## 手动场景页

打开 `http://127.0.0.1:8791/tests/_script_host.html`，建议检查 360px、412px 手机宽度和桌面宽度。

- **酒馆原生设置**：默认 / 文档样式、隐藏头像、楼层 / AI回复计时 / token 显示、箭头和计数器组合、所有消息的重roll控件。
- **消息场景**：沉浸布局、长名字、展开操作、七个编辑按钮、添加新楼、更新为较长计时与 token 数。
- **脚本实例**：打开实际设置面板、重启、双开、停用最早实例。每个实例在 `_instance_host.html` 隐藏 iframe 中运行，停用通过导航触发浏览器原生 `pagehide`。
- **状态与尺寸**：展开查看头像位置、正文宽度、各楼控件显隐与底部补偿、面板边界和当前设置。

默认尺寸下，无重roll控件的消息不补底部空带，仅计数器为 24px，有箭头为 49px；沉浸布局由宿主自行预留。标准消息头保留头像原尺寸，紧凑档上限 36px。

`native-states.css` 只复刻验证需要的原生布局规则，包括手机实际全宽但 `--sheldWidth` 仍为 50vw 的情况，不是完整酒馆样式表。

## 自动回归页

打开 `http://127.0.0.1:8791/tests/regression.html`，点击「运行回归验证」。页面会依次检查十组场景并显示逐项结果：

1. 标准横排、原节点数据更新、小型系统消息。
2. 进入 / 退出文档模式时还原与重新搬移，正文不越界。
3. 隐藏头像及全部信息后不留空列、空行。
4. 紧凑头像、长名字、展开操作和编辑栏。
5. 箭头、计数器、旧楼重roll补偿。
6. 阅读宽度 960 / 1200px、手机限宽及旧版全屏设置。
7. 仅窄屏的桌面布局、头像放大和跨断点搬移。
8. 手机 / 横屏面板边界、关闭和立即重开。
9. 实例交接、旧 pagehide、停用不复活及节点还原。
10. 新楼搬移、无关设置不重搬、暂停时 UI 样式恢复。

每组在隔离宿主 iframe 中运行，生产脚本仍经隐藏子 iframe 注入宿主。回归过程中暂用本浏览器的脚本设置，结束后恢复原值；尺寸变化按目标条件等待，避免将异步 resize 当成布局失败。

这些页面用于原生状态的局部回归。真实酒馆中的主题、扩展组合和移动设备仍需实际验证。
